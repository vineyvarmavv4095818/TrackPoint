About TrackPoint

TrackPoint is a real-time International Space Station (ISS) tracking web application built using Flask, Leaflet.js and external space APIs.

Features

  • Live ISS Location
  • Interactive World Map
  • Real-time Latitude & Longitude
  • Altitude & Velocity
  • Current Country Detection
  • Astronauts in Space
  • ISS Orbit Trail

🛠 Technologies Used

  • Python
  • Flask
  • HTML5
  • CSS3
  • JavaScript
  • Leaflet.js
  • Jinja templates

APIs Used

  • Where The ISS At API
  • OpenStreetMap Nominatim API
